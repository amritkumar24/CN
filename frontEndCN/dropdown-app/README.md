# Simple React Dropdown

A small React app with a reusable dropdown. The dropdown shows a list of choices and displays the one you select.

## Features

- Hover over the button to open the dropdown. On a touch screen, tap the button.
- Pass the options to the dropdown using the `items` prop.
- Choose an option to close the list and show your choice on the button.

## Technologies

React, Vite, JavaScript, and CSS.

## Run the project

Install Node.js 20.19+ or 22.12+. Open a terminal in the `dropdown-app` folder and run:


npm install
npm run dev


Open the local address shown in the terminal.
