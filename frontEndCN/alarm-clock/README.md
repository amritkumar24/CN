
# Alarm Clock

A responsive alarm clock application developed using HTML, CSS, and vanilla JavaScript.

## Features

- Live digital clock displaying hours, minutes, seconds, and AM/PM.
- Real-time clock updates every second.
- Set multiple alarms using a 12-hour time format.
- Input validation for hours, minutes, and seconds.
- Display all active alarms in a list.
- Delete individual alarms.
- Display a JavaScript alert when an alarm rings.
- Automatically remove alarms after they ring.
- Support multiple alarms scheduled for the same time.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Download or clone the repository.
2. Open the `frontEndCN/alarm-clock` folder.
3. Open `index.html` in a web browser.
4. Set an alarm using the input fields and click **Set Alarm**.
5. Manage alarms using the Delete buttons.

## Notes

- Alarms work while the webpage remains open.
- Alarms are stored temporarily in memory and are cleared when the page is refreshed.
- No external JavaScript libraries or frameworks are used.
