# Meal App

A simple app to search for meals, view their instructions, and save favourite meals.

The meal information comes from TheMealDB API.

## Features

- Search for meals as you type.
- View a meal's image and instructions.
- Add meals to favourites.
- View and remove favourite meals.
- Save favourites in the browser using localStorage.
- Use the app on desktop and mobile screens.

## Technologies Used

- HTML
- CSS
- JavaScript
- TheMealDB API
- localStorage

## Project Files

- `index.html` — Home page and meal search
- `meal.html` — Meal details page
- `favourites.html` — Favourite meals page
- `style.css` — Styles for the app
- `script.js` — Search and add meals to favourites
- `meal.js` — Display meal details
- `favourites.js` — Display and remove favourite meals
- `README.md` — Information about the project

## How to Run the App

1. Open the `meal-app` folder in VS Code.
2. Install the **Live Server** extension if you do not have it.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Type a meal name in the search box.

You need an internet connection to load meals and images.

## How to Use the App

1. Search for a meal on the home page.
2. Click a meal's image or name to see its details.
3. Click **Add to Favourites** to save a meal.
4. Open **My Favourites** to view or remove saved meals.

Your favourites are saved in the browser. They remain after refreshing the page, but may be removed if you clear the browser's site data.

## API

This app uses [TheMealDB API](https://www.themealdb.com/api.php).
